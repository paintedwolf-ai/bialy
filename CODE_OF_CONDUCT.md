# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It is adopted by reference rather than copied here,
so that the text you read is the current, authoritative one.

In short: be decent to people. Assume the person on the other side is acting
in good faith, disagree about the work rather than about each other, and
accept that "no" is sometimes the answer.

## Scope

This applies in every project space — issues, pull requests, Discussions,
commit messages, code review, and the Hugging Face repositories' discussions
— and when you are representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to **info@paintedwolf.ai**. Reports
are read by the maintainer and are not shared further except as needed to
act on them. Do not file a code-of-conduct report as a public issue.

## Enforcement

The maintainer may edit, hide, lock, or delete contributions and may block
accounts, at their discretion. Where a decision is not obvious, it will be
explained. Having a contribution declined is not a code-of-conduct matter —
see [`CONTRIBUTING.md`](CONTRIBUTING.md).
